# Luigi Colella Garofalo

MSc student in Electrical and Electronics Engineering at EPFL, in Lausanne. Before that I did my Bachelor in Computer Science and Engineering at the University of Bologna, with an exchange at UC Santa Barbara.

I'm mostly into physical design and EDA: taking RTL to a routed layout with Synopsys Fusion Compiler, open-source flows with Yosys and nextpnr, and routing algorithms for 3D chips.

### Projects

- **[fast-3d-router](https://github.com/Bubagna/fast-3d-router)**: C++ router for the Partcl 3D routing challenge, for two hybrid-bonded dies. Negotiated congestion and local search, with results close to the top of the leaderboards in minutes on a laptop.
- **[spectre-riscv](https://github.com/Bubagna/spectre-riscv)**: 5-stage RV32I core in SystemVerilog with a dynamic branch predictor, checked against a Python reference model. Work in progress, the plan is to run a Spectre v1 attack on it and fix it in hardware.

I also make small web apps for myself, like [shelf](https://github.com/Bubagna/shelf) for the books I read and [pocket](https://github.com/Bubagna/pocket) for my expenses.
